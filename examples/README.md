# Examples

Short, self-contained scripts that run in seconds. CI runs every script here
(`just example`), so they stay in step with the API.

| Script | What it shows |
| --- | --- |
| `minimal_example.py` | RHF on benzene, then the π space selected by projection onto the C 2pz AOs |

The full AEGISS workflow, with the DMRG entropy screening, is in the
[tutorials](../docs/tutorials/).
