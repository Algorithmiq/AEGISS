# Configuration

All four dataclasses are frozen (immutable) and validate their inputs on construction.
Import them from the top-level package or from `aegiss.config_dataclasses`:

```python
from aegiss import DMRGConfig, EntropyConfig, ProjectionConfig, OutputConfig
# or
from aegiss.config_dataclasses import DMRGConfig, EntropyConfig, ProjectionConfig, OutputConfig
```
