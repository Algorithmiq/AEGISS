    Active Space

    Functions for selecting active space orbitals. The high-level entry point select_aegiss runs the full pipeline; the lower-level screening functions can be called independently for custom workflows.

    select_aegiss(mol: Any, mf: Any, dmrg_config: DMRGConfig, entropy_config: EntropyConfig, projection_config: ProjectionConfig, output_config: OutputConfig) -> np.ndarray | dict[str, np.ndarray]

    Run the full AEGISS active space selection pipeline.

    Runs DMRG on the specified CAS, then filters the resulting orbitals through entropy screening and AO projection. An orbital is included in the final active space when it has been selected by both criteria. Therefore, only highly entangled orbitals are kept. These orbitals must also have significant contribution on the specified AOs.

    For an unrestricted (UHF) mean-field the whole pipeline runs per spin channel: when dmrg_config.spin_soe resolves to spin-resolved the alpha and beta channels are screened on their own entropy windows, otherwise they share one spin-summed window; either way the AO projection is done per spin. The alpha and beta selections are returned split and are not reconciled into a single spatial active space -- index k denotes a different MO in each channel, so no common spatial index set is defined here.

    Parameters:

    Name Type Description Default
    mol Mole

    Molecular geometry and basis set.

    		 required
    mf SCF

    Converged mean-field object.

    		 required
    dmrg_config DMRGConfig

    Configuration for the DMRG calculation (CAS size, bond dimension, symmetry).

    		 required
    entropy_config EntropyConfig

    Configuration for the entropy-based screening step.

    		 required
    projection_config ProjectionConfig

    Configuration for the AO projection-based screening step.

    		 required
    output_config OutputConfig

    Configuration for output options (file saving, plots).

    		 required

    Returns:

    Name Type Description
    active_indices np.ndarray of int, or dict[str, np.ndarray]

    Sorted orbital indices of the selected active space. A single array for a restricted mean-field; a split {"alpha": ..., "beta": ...} mapping (kept separate, not reconciled) for an unrestricted one. When no orbital passes the entropy screening, an empty flat np.ndarray is returned, also for an unrestricted reference.

    def select_aegiss(
    mol: Any,
    mf: Any,
    dmrg_config: DMRGConfig,
    entropy_config: EntropyConfig,
    projection_config: ProjectionConfig,
    output_config: OutputConfig,
) -> np.ndarray | dict[str, np.ndarray]:
    """Run the full AEGISS active space selection pipeline.

    Runs DMRG on the specified CAS, then filters the resulting orbitals
    through entropy screening and AO projection.  An orbital is included
    in the final active space when it has been selected by *both* criteria.
    Therefore, only highly entangled orbitals are kept. These orbitals
    must also have significant contribution on the specified AOs.

    For an unrestricted (UHF) mean-field the whole pipeline runs per spin
    channel: when ``dmrg_config.spin_soe`` resolves to spin-resolved the alpha
    and beta channels are screened on their own entropy windows, otherwise they
    share one spin-summed window; either way the AO projection is done per spin.
    The alpha and beta selections are returned split and are **not** reconciled
    into a single spatial active space -- index *k* denotes a different MO in
    each channel, so no common spatial index set is defined here.

    Args:
        mol (pyscf.gto.Mole): Molecular geometry and basis set.
        mf (pyscf.scf.hf.SCF): Converged mean-field object.
        dmrg_config (DMRGConfig): Configuration for the DMRG calculation (CAS size, bond dimension, symmetry).
        entropy_config (EntropyConfig): Configuration for the entropy-based screening step.
        projection_config (ProjectionConfig): Configuration for the AO projection-based screening step.
        output_config (OutputConfig): Configuration for output options (file saving, plots).

    Returns:
        active_indices (np.ndarray of int, or dict[str, np.ndarray]): Sorted
            orbital indices of the selected active space. A single array for a
            restricted mean-field; a split ``{"alpha": ..., "beta": ...}``
            mapping (kept separate, not reconciled) for an unrestricted one.
            When no orbital passes the entropy screening, an empty flat
            ``np.ndarray`` is returned, also for an unrestricted reference.
    """
    active_orbs, virt_orbs = get_subspaces_from_cas(
        mf, ncas=dmrg_config.ncas, nelecas=dmrg_config.nelecas
    )
    spin_resolved = dmrg_config.spin_resolved()
    _energy, soe1 = run_dmrg_subprocess(
        mf,
        ncas=dmrg_config.ncas,
        nelecas=dmrg_config.nelecas,
        symm_type=dmrg_config.symm_type,
        max_bond_dim=dmrg_config.max_bond_dim,
        verbosity=dmrg_config.verbosity,
        unrestricted=dmrg_config.unrestricted,
        reorder=dmrg_config.reorder,
        spin_resolved=spin_resolved,
    )
    _maybe_plot_soe(output_config, active_orbs, virt_orbs, soe1)

    screened = _screen_by_entropy(
        entropy_config,
        active_orbs,
        virt_orbs,
        soe1,
        spin_resolved=spin_resolved,
    )
    if _screening_empty(screened):
        logger.info(
            "No orbitals passed the entropy screening step. Consider adjusting the "
            "EntropyConfig.fraction or using 'global' ranking for a more inclusive selection."
        )
        return np.array([], dtype=int)

    if output_config.save_orb:
        _save_entropy_orbitals(mol, mf, screened, output_config)

    base_path = (
        str(Path(output_config.saving_folder) / output_config.saving_prefix)
        if output_config.save_plots
        else None
    )
    logger.info(
        "Ranking orbitals for AO projection based on %s contribution.",
        projection_config.ranking,
    )
    passes = _ao_projection_passes(screened, projection_config.ranking)
    active_indices = _collect_active_indices(mf, projection_config, passes, base_path)

    if output_config.save_orb:
        _save_active_orbitals(mol, mf, active_indices, output_config)
    if output_config.save_plots:
        _plot_active(mol, mf, active_indices, projection_config, output_config)

    return active_indices

    def select_by_entropy(
    occ_orbs: np.ndarray,
    virt_orbs: np.ndarray,
    soe1: np.ndarray | None,
    fraction: float = 0.1,
    fraction_type: Literal["r", "a"] = "r",
    ranking: Literal["global", "subset"] = "global",
) -> tuple[list[tuple[int, float]], list[tuple[int, float]]]:
    """Select active orbitals by single-orbital entanglement entropy.

    Args:
        occ_orbs (np.ndarray, shape (n_occ,)): Indices of occupied orbitals.
        virt_orbs (np.ndarray, shape (n_virt,)): Indices of virtual orbitals.
        soe1 (np.ndarray, shape (n_occ + n_virt,)): Single-orbital entropies for all orbitals.
        fraction (float, optional): Threshold on the entropy value. Interpretation depends on *fraction_type*.
        fraction_type ({'r', 'a'}, optional): ``'r'`` normalises entropy values by the maximum before thresholding;
            ``'a'`` applies *fraction* as an absolute threshold.
        ranking ({'global', 'subset'}, optional): ``'global'`` ranks all orbitals together; ``'subset'`` ranks occupied
            and virtual subspaces separately.

    Returns:
        selected_occ (list of tuple[int, float]): Selected occupied orbitals with entropy values.
        selected_virt (list of tuple[int, float]): Selected virtual orbitals with entropy values.

    Raises:
        ValueError: If *soe1* is not 1-D (e.g. a spin-resolved ``(2, ncas)``
            array; use :func:`select_by_spin_entropy` for that).
    """
    logger.info("----------------Entropy Screening for AEGISS----------------\n")
    if soe1 is None:
        logger.info("No single-orbital entropies provided. Returning empty selection.")
        return [], []
    if np.ndim(soe1) != 1:
        msg = (
            "select_by_entropy expects a 1-D (spin-summed) single-orbital entropy "
            f"array; got shape {np.shape(soe1)}. Spin-resolved (2, ncas) entropies "
            "must be screened per channel with select_by_spin_entropy (the alpha "
            "and beta channels are thresholded independently)."
        )
        raise ValueError(msg)
    if ranking == "global":
        logger.info("Using global ranking of orbitals by entropy values.")
        selected_occ, selected_virt = _global_entropy_ranking(
            soe1, fraction_type, fraction, occ_orbs, virt_orbs
        )
    else:
        logger.info(
            "Using relative ranking of orbitals by entropy values within the subspace."
        )
        n_occ = len(occ_orbs)
        selected_occ = _relative_entropy_ranking(
            soe1[:n_occ], fraction_type, fraction, occ_orbs
        )
        selected_virt = _relative_entropy_ranking(
            soe1[n_occ:], fraction_type, fraction, virt_orbs
        )

    for i in selected_occ:
        logger.info(
            "\tSelected occupied orbital %d: S(1) = %.4f", to_display(i[0]), i[1]
        )
    for i in selected_virt:
        logger.info(
            "\tSelected virtual orbital %d:  S(1) = %.4f", to_display(i[0]), i[1]
        )

    return selected_occ, selected_virt

    def select_by_spin_entropy(
    occ_orbs: np.ndarray,
    virt_orbs: np.ndarray,
    soe1: np.ndarray | None,
    fraction: float = 0.1,
    fraction_type: Literal["r", "a"] = "r",
    ranking: Literal["global", "subset"] = "global",
) -> dict[str, tuple[list[tuple[int, float]], list[tuple[int, float]]]]:
    """Screen the alpha and beta channels independently from a spin-resolved SOE.

    For a spin-polarised target the single spin-orbital entropies
    ``H(n_alpha)`` and ``H(n_beta)`` differ between channels (e.g. an open-shell
    SOMO is entangled in one spin channel and frozen in the other), so each
    channel is thresholded on its own. This yields a *split* selection: the alpha
    and beta active windows may contain different orbitals.

    Args:
        occ_orbs (np.ndarray): Occupied orbital indices of the screening window
            (shared by both spin channels; the split is in which of them each
            channel keeps).
        virt_orbs (np.ndarray): Virtual orbital indices of the screening window.
        soe1 (np.ndarray, shape (2, n_occ + n_virt)): Spin-resolved single
            spin-orbital entropies (row 0 = alpha, row 1 = beta), as returned by
            ``run_dmrg_subprocess(..., spin_resolved=True)``. ``None`` returns
            an empty selection for both channels.
        fraction (float, optional): Same meaning as in :func:`select_by_entropy`;
            a single value is used for both channels.
        fraction_type ({'r', 'a'}, optional): Same meaning as in
            :func:`select_by_entropy`.
        ranking ({'global', 'subset'}, optional): Same meaning as in
            :func:`select_by_entropy`; applied to each channel independently.

    Returns:
        selection (dict[str, tuple[list, list]]): ``{"alpha": (occ_alpha,
            virt_alpha), "beta": (occ_beta, virt_beta)}``, each entry an
            ``(index, entropy)`` list as from :func:`select_by_entropy`.

    Raises:
        ValueError: If *soe1* is not a ``(2, ncas)`` array.
    """
    if soe1 is None:
        logger.info("No single-orbital entropies provided. Returning empty selection.")
        return {"alpha": ([], []), "beta": ([], [])}
    soe = np.asarray(soe1, dtype=float)
    if soe.ndim != 2 or soe.shape[0] != 2:
        msg = (
            "select_by_spin_entropy expects a spin-resolved (2, ncas) SOE array "
            f"(row 0 = alpha, row 1 = beta); got shape {soe.shape}. For a "
            "spin-summed 1-D array use select_by_entropy."
        )
        raise ValueError(msg)

    selection: dict[str, tuple[list[tuple[int, float]], list[tuple[int, float]]]] = {}
    for spin, channel in enumerate(("alpha", "beta")):
        logger.info("=============== %s channel ===============", channel.upper())
        selection[channel] = select_by_entropy(
            occ_orbs=occ_orbs,
            virt_orbs=virt_orbs,
            soe1=soe[spin],
            fraction=fraction,
            fraction_type=fraction_type,
            ranking=ranking,
        )
    return selection

    Select active orbitals by their projection onto a set of target AOs.

    Parameters:

    Name Type Description Default
    mf SCF or KohnShamDFT

    Mean-field object containing the molecular orbitals and occupation numbers.

    		 required
    ao_labels list[str | list[str]]

    List of AO label entries. Each entry is either a single label string (e.g. "Fe 3d") or a list of strings treated as one group (e.g. ["Fe 3d", "Fe 4d"]). Entries can be freely mixed, e.g. ["C 2pz", "Fe 3d", ["Fe 3d", "Fe 4d"]].

    		 required
    projected_basis str or None, default 'minao'

    Basis set to use for the projection. None uses the original basis. A minimal basis (e.g. 'minao') helps focus the selection on chemically relevant orbitals and reduces noise from diffuse functions.

    		 'minao'
    contribution_type {'r', 'a'}, default 'a'

    Relative ('r', each group's weights divided by their maximum over the search space) or absolute ('a') contribution.

    		 'a'
    contribution float, list of float, or dict, default 0.0

    Threshold for selecting orbitals based on their contribution. A single float applies to all AO groups; a list specifies per-group thresholds and should match the length of ao_labels; on a length mismatch a warning is logged and the first value is used for every group. Ignored when top_n is given. For an unrestricted mean-field it may also be a spin-resolved {"alpha": ..., "beta": ...} mapping (each value itself a float or per-group list), applying a different threshold to each spin channel. A non-dict value is shared by both channels. A dict is rejected for a restricted mean-field.

    		 0.0
    top_n int or list of int

    Alternative to contribution thresholding. Selects the top N orbitals per AO group. A list specifies per-group counts; on a length mismatch with ao_labels a warning is logged and the first value is used for every group.

    		 None
    restricted_space list of int, list of tuple, tuple of lists, dict

    Orbital indices to restrict selection to. Can be a plain list of integers (e.g. list(range(34, 131))), a list of (index, entropy) pairs, or a (occ_list, virt_list) tuple from select_by_entropy. For an unrestricted mean-field it may also be a spin-resolved {"alpha": ..., "beta": ...} mapping (as produced by select_by_spin_entropy), in which case each spin channel is restricted to its own space. A non-dict value is shared by both channels. None considers all orbitals.

    		 None
    save_path str or None

    If provided, saves a heatmap of AO contributions to the specified path. For an unrestricted mean-field the alpha/beta channels are written to separate *_alpha / *_beta files.

    		 None
    return_contributions bool, default False

    If True, also return the per-group AO contributions so they can be passed straight to :func:~aegiss.utils.plotting.plot_ao_contribution for custom plots.

    		 False

    Returns:

    Name Type Description
    active_indices np.ndarray of int, or dict[str, np.ndarray]

    Selected orbital indices. For a restricted mean-field a single array is returned. For an unrestricted (UHF) mean-field -- detected from a 3D mf.mo_coeff of shape (2, nao, nmo) -- the selection is always done per spin (the AO overlaps are spin-independent, only the MO coefficients differ) and the result is a split {"alpha": ..., "beta": ...} mapping. Whether the two channels share one search space (spin-summed restricted_space) or use their own (spin-resolved dict restricted_space), the alpha and beta selections are kept separate here: they are deliberately not reconciled into a common set of spatial orbitals, since an orbital index refers to a different MO in each spin channel.
    ao_contributions dict, only if *return_contributions* is ``True``

    Group index (position in ao_labels) to (orbital_index, weight) pairs over the whole search space. For an unrestricted mean-field this is a {"alpha": ..., "beta": ...} mapping of such dicts.

    Raises:

    Type Description
    ValueError

    If restricted_space or contribution is a spin-resolved {"alpha", "beta"} dict but mf is restricted.

    mf: Any,
    ao_labels: list[str | list[str]],
    projected_basis: str | None = "minao",
    contribution_type: Literal["r", "a"] = "a",
    contribution: float | list[float] | dict[str, float | list[float]] = 0.0,
    top_n: int | list[int] | None = None,
    restricted_space: _RestrictedSpace = None,
    save_path: str | None = None,
    *,
    return_contributions: bool = False,
) -> (
    np.ndarray
    | dict[str, np.ndarray]
    | tuple[np.ndarray, _AoContributions]
    | tuple[dict[str, np.ndarray], dict[str, _AoContributions]]
):
    """Select active orbitals by their projection onto a set of target AOs.

    Args:
        mf (pyscf.scf.hf.SCF or pyscf.dft.rks.KohnShamDFT):
            Mean-field object containing the molecular orbitals and occupation numbers.
        ao_labels (list[str | list[str]]): List of AO label entries. Each entry is either a single label string
            (e.g. ``"Fe 3d"``) or a list of strings treated as one group
            (e.g. ``["Fe 3d", "Fe 4d"]``). Entries can be freely mixed, e.g.
            ``["C 2pz", "Fe 3d", ["Fe 3d", "Fe 4d"]]``.
        projected_basis (str or None, default 'minao'):
            Basis set to use for the projection. ``None`` uses the original basis.
            A minimal basis (e.g. ``'minao'``) helps focus the selection on
            chemically relevant orbitals and reduces noise from diffuse functions.
        contribution_type ({'r', 'a'}, default 'a'): Relative (``'r'``, each group's weights divided
            by their maximum over the search space) or absolute (``'a'``) contribution.
        contribution (float, list of float, or dict, default 0.0): Threshold for
            selecting orbitals based on their contribution.
            A single float applies to all AO groups; a list specifies per-group
            thresholds and should match the length of *ao_labels*; on a length
            mismatch a warning is logged and the first value is used for every
            group. Ignored when *top_n* is given.
            For an unrestricted mean-field it may also be a spin-resolved
            ``{"alpha": ..., "beta": ...}`` mapping (each value itself a float or
            per-group list), applying a different threshold to each spin channel.
            A non-dict value is shared by both channels. A dict is rejected for a
            restricted mean-field.
        top_n (int or list of int, optional): Alternative to *contribution* thresholding. Selects the top N orbitals
            per AO group. A list specifies per-group counts; on a length
            mismatch with *ao_labels* a warning is logged and the first value is
            used for every group.
        restricted_space (list of int, list of tuple, tuple of lists, dict, optional):
            Orbital indices to restrict selection to. Can be a plain list of
            integers (e.g. ``list(range(34, 131))``), a list of ``(index, entropy)``
            pairs, or a ``(occ_list, virt_list)`` tuple from ``select_by_entropy``.
            For an unrestricted mean-field it may also be a spin-resolved
            ``{"alpha": ..., "beta": ...}`` mapping (as produced by
            ``select_by_spin_entropy``), in which case each spin channel is
            restricted to its own space. A non-dict value is shared by both
            channels. ``None`` considers all orbitals.
        save_path (str or None, optional):
            If provided, saves a heatmap of AO contributions to the specified path.
            For an unrestricted mean-field the alpha/beta channels are written to
            separate ``*_alpha`` / ``*_beta`` files.
        return_contributions (bool, default False): If ``True``, also return the
            per-group AO contributions so they can be passed straight to
            :func:`~aegiss.utils.plotting.plot_ao_contribution` for custom plots.

    Returns:
        active_indices (np.ndarray of int, or dict[str, np.ndarray]):
            Selected orbital indices. For a restricted mean-field a single array
            is returned. For an unrestricted (UHF) mean-field -- detected from a
            3D ``mf.mo_coeff`` of shape ``(2, nao, nmo)`` -- the selection is
            always done per spin (the AO overlaps are spin-independent, only the
            MO coefficients differ) and the result is a split
            ``{"alpha": ..., "beta": ...}`` mapping. Whether the two channels
            share one search space (spin-summed *restricted_space*) or use their
            own (spin-resolved dict *restricted_space*), the alpha and beta
            selections are kept separate here: they are deliberately *not*
            reconciled into a common set of spatial orbitals, since an orbital
            index refers to a different MO in each spin channel.
        ao_contributions (dict, only if *return_contributions* is ``True``):
            Group index (position in *ao_labels*) to ``(orbital_index, weight)``
            pairs over the whole search space. For an unrestricted mean-field
            this is a ``{"alpha": ..., "beta": ...}`` mapping of such dicts.

    Raises:
        ValueError: If *restricted_space* or *contribution* is a spin-resolved
            ``{"alpha", "beta"}`` dict but *mf* is restricted.
    """
    logger.info("----------------AO Projection Screening for AEGISS----------------\n")
    logger.info("AO labels for projection: %s", ao_labels)

    logger.info("Contribution threshold: %s", contribution)
    logger.info("Contribution type: %s", contribution_type)

    if top_n is not None:
        logger.info("Top N orbitals to select: %s", top_n)

    if projected_basis is not None:
        logger.info("Using projected basis for AO projection: %s", projected_basis)
    else:
        logger.info("Using molecule for AO projection")

    labels_idx: dict[int, str | list[str]] = dict(enumerate(ao_labels))
    mo_coeff = np.asarray(mf.mo_coeff)

    if mo_coeff.ndim != 3:
        if isinstance(restricted_space, dict):
            msg = (
                "A spin-resolved restricted_space ({'alpha', 'beta'} dict) requires "
                "an unrestricted mean-field with a 3D mo_coeff; got a restricted one."
            )
            raise ValueError(msg)
        if isinstance(contribution, dict):
            msg = (
                "A spin-resolved contribution ({'alpha', 'beta'} dict) requires an "
                "unrestricted mean-field with a 3D mo_coeff; got a restricted one."
            )
            raise ValueError(msg)
        resolved_contribution, resolved_top_n = _resolve_thresholds(
            contribution, top_n, len(ao_labels)
        )
        indices, contributions = _run_ao_selection(
            mf=mf,
            ao_labels=ao_labels,
            full_mo_coeff=mo_coeff,
            space=_resolve_space(mf, restricted_space),
            resolved_contribution=resolved_contribution,
            resolved_top_n=resolved_top_n,
            contribution_type=contribution_type,
            projected_basis=projected_basis,
            save_path=save_path,
            labels_idx=labels_idx,
        )
        return (indices, contributions) if return_contributions else indices

    logger.info(
        "Unrestricted mean-field detected (mo_coeff shape %s); screening the "
        "alpha and beta channels per spin (%s search space).",
        mo_coeff.shape,
        "per-channel" if isinstance(restricted_space, dict) else "shared",
    )
    selection: dict[str, np.ndarray] = {}
    channel_contributions: dict[str, _AoContributions] = {}
    for spin, channel in enumerate(("alpha", "beta")):
        logger.info("=============== %s channel ===============", channel.upper())
        # A dict restricted_space carries its own window per spin channel
        # (spin-resolved entropy screening); anything else is shared by both.
        channel_space = (
            restricted_space[channel]
            if isinstance(restricted_space, dict)
            else restricted_space
        )
        # A dict contribution carries its own threshold(s) per spin channel;
        # anything else is shared by both.
        channel_contribution = (
            contribution[channel] if isinstance(contribution, dict) else contribution
        )
        resolved_contribution, resolved_top_n = _resolve_thresholds(
            channel_contribution, top_n, len(ao_labels)
        )
        selection[channel], channel_contributions[channel] = _run_ao_selection(
            mf=mf,
            ao_labels=ao_labels,
            full_mo_coeff=mo_coeff[spin],
            space=_resolve_space(mf, channel_space),
            resolved_contribution=resolved_contribution,
            resolved_top_n=resolved_top_n,
            contribution_type=contribution_type,
            projected_basis=projected_basis,
            save_path=_channel_save_path(save_path, channel),
            labels_idx=labels_idx,
        )
    return (selection, channel_contributions) if return_contributions else selection

    AO label format

    ao_labels follow PySCF's search_ao_label convention:

    "C 2pz"                             # this shell on every (untagged) carbon atom
["Fe 3dxz", "Fe 3dyz", "Fe 3dz^2"]  # several orbitals in one group
"C.1 2pz"                           # only carbons labelled C.1 in the geometry

    The Element.N form matches atoms whose label in the geometry is Element.N, such as the tags written by MolTagger. N is the tag you chose, not the position of the atom in the molecule. Tagged atoms are no longer matched by the plain element label: with a geometry containing C.1 and C atoms, "C 2pz" selects only the untagged carbons.
